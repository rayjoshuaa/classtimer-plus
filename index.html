ClassTimer+

The calm countdown timer for your classroom screen — time the whole class can see, without the alarm-clock stress.

How to use

  1. Pick a preset, or type a custom time and press Set.
  2. Press Start. The ring changes colour as time runs down — green, then amber, then red.
  3. Use − 1 min / + 1 min to adjust, even while the timer is running.
  4. At zero the chime sounds. If overtime is on, the timer keeps counting up so you can wrap up calmly.

Shortcuts: Space start / pause · − / + one minute · R reset · F fullscreen
