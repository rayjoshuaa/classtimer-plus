# ⏱️ ClassTimer+

**The calm countdown timer for your classroom screen.**

A free, single-page classroom timer built for the projector: huge readable numbers, a progress ring that changes colour as time runs down, a gentle chime instead of a startling alarm — and if the class needs a moment more, it quietly counts *overtime* instead of just stopping.

🔗 **Live:** https://classtimer-plus.pages.dev

## Why it's different

Most free classroom timers are cluttered with ads, need an account, or blast a harsh buzzer. ClassTimer+ is:

- **Traffic-light stages** — green (on track) → amber (halfway) → red (almost done), so students can *see* time passing
- **Gentle three-note chime** at zero — calm, not a fire alarm (can be muted)
- **Overtime counting** — after zero it counts up (+00:37) so wrap-up doesn't feel rushed
- **One-tap presets** (1–30 min) plus custom minutes/seconds
- **±1:00 buttons** for "one more minute" — or one less — without restarting
- **Fullscreen mode** and keyboard shortcuts (Space, R, F)
- **Remembers your last timer** between lessons
- **No sign-up, no ads, works offline** — it's a single HTML file

## How teachers use it

1. Open the page on the classroom computer and press ⛶ Fullscreen
2. Tap a preset (or set a custom time) and press Start
3. The class watches the ring: green means plenty of time, red means pencils down soon

Perfect for timed writing, group work rotations, quizzes, clean-up time, and transitions.

## Tech

One self-contained `index.html` (HTML + CSS + vanilla JS + Web Audio API). No build step, no dependencies. Hosted on Cloudflare Pages.
