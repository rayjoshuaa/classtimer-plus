# ClassTimer+ — v2.1.5 (shadcn/ui rebuild)

A free, big-screen classroom countdown timer. No sign-up; the chosen time is
stored in the browser (`localStorage` key `classtimer_total`) and the app
builds to a fully static site.

This is the **shadcn/ui rebuild** of ClassTimer+ (v2.0.0, icon update in
v2.1.5). The previous vanilla build (v1.9.1) still lives in
`../classtimer-plus/` and is not touched by this project.

**Icon:** the black & white Teacher Tools icon set lives in `../icons-bw/`.
ClassTimer+ uses the `timer` icon as `public/icon.svg` — its favicon and the
brand mark above the app title.

## Stack

- React 19 + Vite 8 + TypeScript
- Tailwind CSS **v4** (via `@tailwindcss/vite`)
- shadcn/ui — `radix-nova` style, `neutral` base colour, CSS variables,
  `lucide` icons (see `components.json`)
- lucide-react icons

Setup was done the standard shadcn way for an existing Vite project:
Tailwind v4 and the `@/` import alias were configured first (per the official
shadcn Vite installation docs), then:

```bash
npx shadcn@latest init -b radix -p nova --no-monorepo -y
npx shadcn@latest add button card badge input label switch dialog tooltip kbd separator progress toggle-group button-group -y
```

Note: the shadcn CLI wrote the generated files into a literal `@/` folder in
the project root instead of resolving the alias to `src/`. The generated
component files were moved **verbatim, unmodified** into
`src/components/ui/` (and `src/lib/utils.ts`). No component source was
hand-written or altered.

## shadcn/ui components used

Every UI element in the app is one of these official components from
`src/components/ui/`:

- **Button** — Start/Pause/Resume, Reset, Set, +1 min / −1 min, fullscreen,
  how-to trigger, footer portfolio link (`asChild`)
- **ButtonGroup** — the −1 min / +1 min adjust controls
- **Card** (`CardHeader`, `CardTitle`, `CardDescription`, `CardContent`,
  `CardFooter`) — the timer panel and its sections
- **Badge** — "Teacher Tools" eyebrow and the stage indicator
  (Ready / On track / Halfway there / Almost done / Paused / Time's up,
  using the `default`, `secondary`, `outline` and `destructive` variants)
- **Input** — custom minutes and custom seconds
- **Label** — Time, Adjust, custom minute/second fields, and both switches
- **Switch** — gentle chime at zero (default on), count overtime (default on)
- **Dialog** (`DialogTrigger`, `DialogContent`, `DialogHeader`,
  `DialogTitle`, `DialogDescription`) — How to use
- **Tooltip** (`TooltipProvider`, `Tooltip`, `TooltipTrigger`,
  `TooltipContent`) — fullscreen button tooltip
- **Kbd** — keyboard shortcuts in the footer and the How to use dialog
- **Separator** — section dividers inside the card
- **Progress** — stage/time-remaining progress (replaces the v1.9.1 SVG ring;
  shadcn/ui has no ring component, and no custom SVG ring was built)
- **ToggleGroup / ToggleGroupItem** — the 1, 2, 3, 5, 10, 15, 20, 30 min
  presets (plus the `toggle` component the CLI installs as its dependency)

Layout is Tailwind utility classes only, and the countdown time itself is
plain text inside the Card. There is no custom colour palette, no
glassmorphism, and no custom CSS UI: `src/index.css` is the file generated by
`shadcn init` (shadcn theme tokens, Geist font as shipped by the preset).

## Features (carried over from v1.9.1)

- Presets 1, 2, 3, 5, 10, 15, 20, 30 min (default 5 min), custom minutes +
  seconds with Set (fields clear after Set; empty input shows
  "Enter minutes or seconds first" and focuses the minutes field)
- Start / Pause / Resume, Reset, +1 min / −1 min (works running or paused;
  −1 min on an untouched timer reduces the total)
- Stages: more than 50% left = On track, more than 20% = Halfway there,
  otherwise Almost done; at zero = Time's up
- Gentle WebAudio chime at zero (523.25 / 659.25 / 783.99 Hz sine notes,
  staggered 0.22 s), with a sound switch (default on)
- Overtime switch (default on): counts up `+MM:SS` after zero with
  "Overtime — wrap up and finish up"; off stops at 00:00
- Fullscreen button, How to use dialog
- Keyboard: `Space` start/pause (not while typing in an input or when a
  button is focused), `+` / `−` one minute, `R` reset, `F` fullscreen
- Tab title updates to `ClassTimer+ | MM:SS` while the timer is active,
  sr-only `aria-live` announcements, footer
  "© 2026 Ray Joshua. All rights reserved." linking to the portfolio

## Run and build

```bash
npm install
npm run dev      # local development
npm run build    # type-check (tsc -b) + production build into dist/
npm run preview  # preview the production build
```
